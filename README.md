## 정오표

### 155p

**수정 전**

> 3. 클로드 코드에서 다음 명령으로 OMC를 설치합니다.

**수정 후**

> 3. OMC는 다음 2개의 명령어로 설치합니다.

#### 1단계 – 마켓플레이스 등록

클로드 코드 세션을 연 뒤 다음 명령을 입력합니다.

```
/plugin marketplace add https://github.com/Yeachan-Heo/oh-my-claudecode
```

이 명령은 플러그인을 곧바로 설치하지 않습니다. 해당 깃허브 저장소를 "플러그인을 내려받아 올 목록(마켓플레이스)"으로 클로드 코드에 등록하는 단계입니다. 서점을 등록해 두는 것에 가깝다고 이해하면 됩니다.

#### 2단계 – 플러그인 설치

등록이 끝났다면 이어서 다음 명령을 입력합니다.

```
/plugin install oh-my-claudecode
```

방금 등록한 마켓플레이스에서 실제로 책을 한 권 골라 꺼내 오는 셈입니다. 설치가 끝나면 OMC의 에이전트와 스킬이 세션에 로드됩니다.

> [!WARNING]
> 초보자가 가장 자주 걸려 넘어지는 지점입니다. 두 명령을 한꺼번에 복사해 붙여넣으면 실패합니다.
> 슬래시 명령은 한 번에 하나씩 처리되므로, 첫 번째 명령을 입력해 등록이 끝난 것을 확인한 뒤 두 번째 명령을 입력하세요.
